# 同一留出集的数据扩充对照：分析计划

制定时间：2026-10-25，对照组训练开始时；扩充组结果已在前轮公开。

问题：保持架构、代码、预处理、验证集、测试集、训练参数和种子一致，在当前训练集加入87张新增批次图像，是否改善最终坐标点检测？

对照组训练89张原批次图像、1588个真值点；扩充组训练176张图像、4156个点。共同验证集22张、372个点，共同测试集22张、548个点。测试集不再重新随机划分。对照组不使用原113批次中落在验证/测试集的图像训练。

两组均从头训练三个种子42、43、44，每个100轮，batch=8、lr=0.001、UNetDeepBlink、Dice+2×RMSE、XPU bfloat16 AMP和channels-last。扩充组三个已完成模型经代码、原始数据和参数一致性核验后复用，避免无意义重复训练。每个种子按验证损失最低选轮次，在验证集上扫描阈值，最大化F1且Precision不低于p=0.5的参考值；选择最小验证损失的种子作为各组候选模型。所有选择在对照组测试推理之前锁定。

主终点是扩充组减对照组的三种子平均测试micro-F1差值。同时输出各种子Precision、Recall、TP、FP、FN、macro-F1和匹配成功点定位误差中位数；展示全部种子而非只选最高测试分。种子配对按42/43/44，不把它们当作新的独立测试图像。

不确定性：共同抽取22张测试图像的索引，有放回重采样10000次，bootstrap随机种子20261025。两组及所有训练种子使用同一组图像索引；每次先在重采样图像上累计TP/FP/FN，分别求每个训练种子的micro-F1，再求三种子平均差，报告百分位95%区间。不把所有点或66张种子×图像观察当作独立单位，不以平均逐图F1代替micro-F1。本分析不报告显著性p值。

设计和假设核查：样本ID严格配对、两组真值数一致、计数有限且非负、无缺失图像、训练与留出ID不交叉、共同留出数组逐项一致、来源文件键唯一。图像bootstrap要求图像层面的可交换性；当前没有个体或实验批次的完整独立性证据，区间不是生物学外部泛化保证。此处不使用要求正态差值或独立组的t检验，因此不依赖Shapiro或方差齐性筛选。所有案例保留，不依据测试结果删除离群图像。

解释边界：本轮测试已经看过，且更早的仓库实验也曾使用部分图像，属于内部对照，不能称为全新盲测。增加数据同时改变训练图像数、来源、尺寸组成和点数，不能拆解为纯数量收益。相同100轮下，对照组每轮12次、扩充组每轮22次参数更新，总计1200对2200步；这是相同训练方案下的数据扩充效应，不是固定更新次数的纯数据效应。条件于这三个拟合模型的图像bootstrap不包含完整的训练不确定性或重新划分不确定性，种子标准差另外报告。

结果无论正负均完整报告。不会依据当前测试结果重新选阈值、选种子、增加轮次、改标签或改架构。若继续按错误分析开发，最终结论仍需要独立采集并封存的新图像验证。
