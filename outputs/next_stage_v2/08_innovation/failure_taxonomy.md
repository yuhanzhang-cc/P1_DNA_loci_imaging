# 开发集错误分类与标注不确定性

来源仅为固定开发集：176训练图用于定义弱点阈值；22验证图用于原模型seed42错误描述。没有读取测试图作当前结构筛选。

修正匹配、v2阈值下，验证372真值得到TP311、FP68、FN61，F1=0.828229。TP/FP/FN局部z分数中位数分别3.798/2.739/1.647；这支持弱点漏检现象，但不等于已确认光学原因。局部最亮点到事件位置距离中位数分别0.947/1.647/3.309像素。

68个注释相对FP中，43个概率>0.9，31个距21×21邻域最亮像素>3px。训练真值局部z的下四分位定义“弱点”后，验证集中96个弱点检测到51个，召回53.125%。这些定义已在 mechanism_preregistration.json 冻结，不随候选结果修改。

当前分类：低局部对比真值漏检；邻域有更亮结构的定位/判别混淆；高置信但注释不匹配；拥挤多峰或可能标注不确定。patch拼图可见不同错误形态，一些FP仍有点状外观，不能一概认定为背景，更不能据此自动增加标签。未匹配预测逐点列入 annotation_uncertainty_queue.csv。

40/198张开发图已按固定随机种子列出盲法人工复核队列；复核未完成。当前图像浏览是研究者知晓错误类型的探索检查，不能称独立盲法验收。

产物：development_audit/point_events.csv、error_summary.json、development_patches.png，以及人工复核队列。候选训练后按相同脚本和阈值来源重算机制代理；最终结构机制仍需消融，不能凭拼图成立。

这里的“高置信”只表示网络occupancy score>0.9，并非经独立校准的90%正确率；不同模型此项的变化仅描述得分分布，不能单独证明机制或可靠性改善。
