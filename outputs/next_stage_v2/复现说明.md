# 本轮优化的复现入口

在仓库根目录使用已有隔离XPU环境。依赖没有在本轮增加；版本清单见`00_protocol/runtime_packages.txt`，设备与源码快照见各trial目录。

输入固定为`outputs/261024_clean220_random/dna_clean220_random.npz`，220对中的176训练/22验证；原始文件哈希和划分见`00_protocol/data_manifest.csv`。训练过程中不加载测试数组，不重划分，不覆盖历史输出。

```bat
.venv\clean220_xpu\Scripts\python.exe deepblink_pytorch\scripts\optimize_v2.py reference
.venv\clean220_xpu\Scripts\python.exe deepblink_pytorch\scripts\optimize_v2.py screen --models deeploci_evidence deeploci_local
.venv\clean220_xpu\Scripts\python.exe deepblink_pytorch\scripts\optimize_v2.py screen --models deeploci_feature_evidence deepblink_masked_se
```

已完成的trial会保留；不完整的trial会要求先审查，不静默覆盖重跑。若修改模型或协议，应登记新版本和输出目录，不能把旧缓存当作新代码的结果。每项均为seed42、100轮、batch8、Adam lr0.001/weight_decay0、Dice+2RMSE、XPU bfloat16训练，按最低验证损失选择checkpoint；评分统一float32推理，再以固定31个全局阈值最大化验证点micro F1。旧p=0.5精度下限不再使用。

四项完整训练结束后汇总：

```bat
.venv\clean220_xpu\Scripts\python.exe deepblink_pytorch\scripts\summarize_optimization_v2.py
.venv\clean220_xpu\Scripts\python.exe deepblink_pytorch\scripts\probe_evidence_v2.py --model deeploci_feature_evidence --device xpu
.venv\clean220_xpu\Scripts\python.exe deepblink_pytorch\scripts\benchmark_v2_prototypes.py
```

资源测量应在训练任务结束后独立进行。临时证据干预只是依赖性检查，不是从头重训的消融；单种子验证成绩也不是测试提升证明。

主要产物为`validation_comparison.csv`、`size_validation_metrics.csv`、`trial_registry.csv`及`阶段汇报.md`。各trial保留`registered_config.json`、`source_snapshot/`、`source_hashes.json`、`environment.json`、`training_metrics.csv`、`training_curves.png`、`best_model.pt`、`validation_v2/`与错误分析。

新增模型的预测必须保留checkpoint中的model_name、input_size和架构信息，使用各自验证表中的阈值。A/D/D2的几何mask由推理原图尺寸生成，不需要点标注。阈值校准是工作点选择，occupancy score不能直接解释为真实正确率。
