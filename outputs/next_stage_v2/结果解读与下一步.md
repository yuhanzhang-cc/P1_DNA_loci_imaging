# 首轮结构筛查的结论与后续工作

四个候选各完成100轮、seed42，相同176训练/22验证、T_ref及v2点匹配和阈值选择。原主干验证F1为82.82%，A为81.53%，B为79.00%，D为80.76%，D2为79.48%。**本轮没有验证出超过原主干的结构方案，核心架构贡献尚未建立。** 这是单种子、给定配方和31阈值网格下的筛查结果，不是所有架构设置都无效的证明；充分训练调优、三种子正式对照、强基线和重训消融尚未完成。

当前最好仍为原主干参考。其权重来自`outputs/261024_clean220_random/seed_42/best_model.pt`，本轮仅按v2重新选择验证工作点；没有把历史v1分数与新架构分数相减，也没有把此前数据扩充的+12.77个百分点转移为结构贡献。

退步主要体现为召回损失。原主干TP311/FP68/FN61；D为298/68/74，B为284/63/88，D2为275/45/97。低局部对比真值共96个，原主干检出51个，D/B/D2仅检出42/34/30个。D2误报减少23个，却多漏检36个，F1随之下降。局部形态或对比证据可能使模型偏向显著、独立的峰，但这只是与观察相容的解释；不能在缺少重训控制、更多种子和标注复核时把原因定死为某个算子或梯度冲突。

A保持弱点检出51/96，但FP增至77，整体F1下降。256图的F1从0.834286变为0.836364，512图从0.826389变为0.809444；同一阈值下，512图多出15个FP。7张256图上的微小变化不足以证明稳定收益。有效区域SE是工程适配诊断，本轮不支持将它直接作为核心创新。

计数MAE和定位指标必须与检出率一起看。A的逐图计数MAE从2.682略降到2.545，但点F1更低；B的TP定位误差中位数从0.328降到0.301px，但少检27个真值。这些是不同指标的取舍，不能把条件于更容易检出点的定位误差当作整体检测提升。

临时证据干预说明D/D2确实使用了新分支及预测位置；去掉证据或固定网格中心会降低该已训练模型的表现。它不等于从头重训消融，也不能证明分支优于原主干。D的训练图梯度检查同样不足以支持“梯度冲突导致退步”的因果解释。

资源初测使用相同Intel XPU、float32、batch1、5次预热与20次同步计时，且只选两张开发图。512原图的前向中位耗时约：原主干64.0ms、A66.0ms、B62.3ms、D67.3ms、D2 69.4ms。这里不含读图、标准化、解码及叠图；它是本机初测，不是正式跨设备效率结论。D/D2增加了计算成本，没有换来本轮准确率收益。

校准覆盖限制：A的最优阈值0.025位于固定线性网格的最低内部点，未扫描0到0.025之间的更细工作点。下一版可在查看新结果前，为所有方法统一注册覆盖低分和高分尾部的校准规则；不能只对A追加阈值直到出现提升。当前比较保留预先规定的31个候选，不称全局最优。

当前注释来自人工调节TrackMate直径和quality threshold后的XML/CSV导出流程，尚未验证所有点经过独立逐点复核。一些注释相对FP仍呈点状外观，不能自动认定为背景或自动改标签。40张开发图的盲法复核队列已准备好；任何标签修订应形成新数据版本，对所有方法公平使用。源容器和生物学分组边界见`00_protocol/annotation_qc.md`。

本轮修复了三处实现问题：Hungarian点匹配可能为了缩短距离而少配有效点；旧诊断脚本从补齐NPZ读取图像时遗漏原图尺寸裁切；旧预测/评价CLI在offset恰为1的网格边界可能附上邻格分数。新v2评分从源网格直接取分数，原图尺寸处理正确；后两项工具修复不改变已保存的本轮模型评分。新增geometry-only mask、development-only数据读取及checkpoint模型注册均有定向检查。

下一步按证据推进：

1. 先完成开发图盲法标签复核，并核查弱点、拥挤邻峰与来源尺度的错误定义。保留当前原始参考和失败结果，避免模型引导的重标变成新的评价偏差。
2. 核查训练/选模目标与点F1的关系。目前每项仍以最低Dice+2RMSE选择checkpoint；若下一版研究点F1选模、弱点增强或新的目标函数，须对原主干与核心候选共同登记，归为训练贡献，不直接称架构收益。
3. 架构研究优先验证细粒度弱点信息是否被网格/下采样损失：用已计划的全分辨率heatmap+offset及Spotiflow/Piscis等强方法建立参考，再考虑细粒度点分支与较大范围或尺度自适应背景上下文的交互。它们都是待验证方向，普通heatmap或注意力本身也不能自动称为新方法。新设计需写清相对最近工作的差异，并设置弱点召回、背景误报、容量和固定中心等可反驳控制。
4. 四个结构槽位已用完。本轮不继续堆第五个模块或启动缺乏支持的核心调参/正式消融；若进一步搜索，应先形成下一版scope及预算与公平性说明。保留候选后再做三种子、同配方归因和最终统一内部测试；当前22张测试图已观察过，独立新采集验证仍另需准备。

所有结论限于本轮开发筛查；没有新的测试集推断，也没有“我们最好”的方法结论。
