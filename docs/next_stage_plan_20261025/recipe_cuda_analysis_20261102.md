## 2. 增强实际改变了什么

注册主终点为三训练seed各自micro-F1的均值；同22张开发验证图、372真值点、96弱点，匹配半径3px。

| 指标 | G0参考 | G0联合增强 | 增强−参考 |
|---|---:|---:|---:|
| micro-F1，均值±sample SD | 0.81975±0.00713 | 0.81988±0.00152 | **+0.00014** |
| Precision，均值 | 84.46% | 84.31% | −0.15个百分点 |
| Recall，均值 | 79.75% | 79.93% | +0.18个百分点 |
| 弱点Recall，均值 | 47.22% | 44.44% | **−2.78个百分点** |
| 非弱点Recall，均值 | 91.06% | 92.27% | +1.21个百分点 |
| macro-F1，均值 | 0.79789 | 0.80152 | +0.00363 |
| FP，三seed均值 | 55.0 | 56.0 | +1.0 |
| 计数MAE/图，均值 | 2.773 | 3.182 | **+0.409，变差** |
| 匹配点平均定位误差/px | 0.4463 | 0.4229 | −0.0234，约降低5.2% |
| 匹配点RMSE/px | 0.5724 | 0.5278 | −0.0446 |

种子配对F1差分别为：seed42 **+0.894个百分点**、seed43 **−0.023个百分点**、seed44 **−0.830个百分点**。平均只增加**0.014个百分点**，一升两降；预声明双侧精确符号翻转检验 **p=1.00**。固定所选模型的10000次配对图像bootstrap区间约为**[−2.14,+2.39]个百分点**；该区间未校正选模，且图像不是已确认的独立生物学重复。

这支持“本轮未建立整体收益”，不能解释成严格证明两配方等价。11个辅助指标的探索性Holm校正均未显著，不添加星号。三seed间F1的SD变小只是描述性现象，不足以认定稳定性已有统计提升。

### 定位改善有多少来自检出集合变化

直接比较平均定位误差会受到“检出了哪些点”的影响。限定每个seed双方均检出的同一批真值点后，共同TP分别260、278、290；每seed平均误差再求均值，参考约**0.4297px**，增强约**0.4164px**，仍有约**0.0134px**描述性下降，但只有两个seed改善，第三个变差。因此不能把完整0.0234px下降全部归于同一批点的定位变准。

固定原模型与阈值，只改变评价半径的探索性结果：1px时F1由0.7571至0.7768，约+1.97个百分点；3px时收益几乎消失。这与部分定位改善相容。注册终点仍是3px，不能事后改用1px作为主结果宣布成功。

### 哪些样本发生了抵消

| 原生尺寸 | 图数/真值点 | 参考F1均值 | 增强F1均值 | 差值 |
|---|---:|---:|---:|---:|
| 256×256 | 7/88 | 0.81943 | 0.79286 | **−2.66个百分点** |
| 512×512 | 15/284 | 0.81972 | 0.82735 | +0.76个百分点 |

256组弱点Recall从38.89%降到30.56%；512组从50.00%至49.07%。256尺寸与新增批次在此验证集中高度相关：8张新增批次图中7张为256。因此不能把差异单独归因于尺寸、padding或来源批次。

将三seed视为重复检测事件统计，增强的非弱TP净增10、弱TP净减8，总TP只净增2，同时FP净增3。这里不是新增了三个生物学重复，也不是8个不同生物学位点的独立统计。这些具体得失解释了为什么总体F1几乎不动。

## 3. 为什么这套增强没有转成整体收益

**直接证据**是弱点/256场景受损、FP未减少、较强点与部分定位改善互相抵消；还不能把损失归因到D4或强度中的某一项，因为本实验只比较联合开关。

**实现层面的解释边界**：强度增强是zscore后的`Z'=aZ+b`，a为正值。它同时缩放信号与背景噪声；局部`(中心−均值)/标准差`在理想正仿射下不变。因此它增加了输入尺度/均值变化，却没有直接模拟低光子、信号相对背景减弱或更低SNR的弱点。D4增加方向/网格相位覆盖，也不增加弱点本身的信息。不能把本轮简单称作“弱信号增强失败”。

有效区域施加偏移、padding仍为0，可能改变256图的有效域与补边统计关系；G0主干仍含全图SE池化。这是待验证假说，不是已经定位的bug。全开发集1584个几何案例及实际坐标重匹配通过，不能用该假说支持直接修改冻结模型。

增强组训练loss更高，验证loss接近参考；这是输入分布和拟合压力变化的表现，不能仅以训练loss直接判断泛化好坏。末期曲线也不足以保证多训100轮会补救。最低验证loss选checkpoint的预声明secondary轨道中，F1反而由**0.81711降至0.79557**，三个seed均下降，说明收益也不稳定依赖另一种合法选模方式。

验证集372点没有同4×4格碰撞；训练集原方向6/4156个点受碰撞影响，D4各方向总数3–6。因此当前大量FN不能主要解释为单槽计数上限。H0仍有价值，因为它还检验空间表示/定位，不是只解决碰撞。

## 4. 0.849为何不能作为本轮的退步幅度

历史原始汇总确认0.848780来自**113版单个模型的12图测试集、213真值点、TP174/FP23/FN39、p=0.4**，其中阈值曾按该测试集扫描。它使用的也是3px micro-F1，并非不同的F1公式。

本轮是**220版176训练/22验证/22内部测试**，实际报告22图开发验证、372点、三seed均值；结构是G0，旧113是UNetDeepBlink。图像组成、训练数据、模型、阈值选择数据及聚合层级均不同。本轮验证中14图来自旧113、8图来自新增107，与旧12测试只重叠3图。**当前验证图另有10张曾属于旧113训练集**，所以也不能直接拿旧权重重新测当前验证集，作为公平R0。

| 可核查参考 | 队列与口径 | F1 |
|---|---|---:|
| 113历史模型 | 自身12图历史测试，单模型/测试阈值扫描 | 0.84878 |
| 旧G0 | 当前同22验证；XPU/bfloat16训练，三seed | 0.82511±0.00378 |
| 新G0参考 | 同22验证；5090/CUDA float32，三seed | 0.81975±0.00713 |
| 新G0增强 | 与新参考严格配对 | 0.81988±0.00152 |
| Spotiflow适配 | 同22验证；4090/CUDA原生配方，三seed | 0.86058±0.00336 |

更相关的历史差值是旧G0的0.82511对新参考0.81975，约**−0.54个百分点**。这两组的划分、训练图顺序和选择预算相同；数值后端、精度和训练执行路径变化，没有独立的后端消融，不能把差值单独归因CUDA或数据量。当前没有证据表明本轮换了220划分或F1公式。

## 5. 最短下一步及可交付版本

**先补R0三seed，再补H0三seed，沿用本次5090与原配方；暂停联合增强的追加搜索和Spotiflow scratch。** R0提供无历史训练重叠的同条件DeepBlink迁移参考；H0判断全分辨率表示是否值得作为后续机制基础。这六次是现有锁定队列，不需要重建训练环境或修改训练源码。

当前G0相对Spotiflow仍有每seed20–23个独有TP，其中12–15个弱点；Spotiflow也有自己的独有弱点。因此存在值得人工核查的互补错误，但不等于融合可直接获益。先完成盲法参考复核，再限定一个针对弱候选/背景判别或定位质量耦合的机制；普通heatmap、flow、注意力拼接本身已有先例，不能默认视为创新。

同时已整理**固定模型检测/定位候选版**：默认既有Spotiflow适配seed42，另附既有G0参考seed42；支持原生2D TIFF→像素坐标CSV、锁定阈值、输入/模型哈希和运行清单。两个入口均在CPU做真实验证图推理检查，无新增训练，原始图和NPZ未装入交付包。详见[候选版使用说明](detection_release_20261102.md)。这是可用工具与结果交付；核心架构领先和独立泛化仍未完成。
