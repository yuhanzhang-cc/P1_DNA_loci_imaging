## 对原两步思路的补充

1. **先固定评价与比较条件，再优化。** 基线名单、调参预算、阈值规则、数据边界现在就定，完整训练可以稍后开展。
2. **“最优化”改为“给定预算内的最佳已验证配置”。** 不能保证全局最优，也不能无限试到赢为止。预算耗尽或改善趋缓都应允许停止。
3. **训练收益和架构收益分别归因。** 数据增强、采样、校准带来的变化，不能全部算作新模块贡献。
4. **基线需要合理调参。** 本方法精调后对比其他方法默认值，证据不足。不同方法可使用合理的自身训练方式，但数据与评估必须一致。
5. **核心方法设计先于充分调参。** 先建立可靠参考配方，提出并筛查任务机制，再分别优化原主干和核心模型；不先把全部资源用于精调DeepBlink。
6. **消融与最终模型冻结衔接。** 开发时做单因素筛查；冻结后完成系统消融。无效模块不必为了“凑创新”留在最终模型。
7. **加入泛化、效率与失败案例。** 当前内部成绩再高，也不能替代独立新图像验证。若本轮未形成有效结构贡献，架构方法路线尚未达成，应如实保留结果并复核研究问题，不能将数据或调参收益重新包装为结构贡献。

## 首轮v2的原研究预算与停止规则（后续执行挂起）

以下是2.1版全研究的52次估算，当前实际完成4次结构筛查。剩余部分挂起，不能与新一轮12次默认叠加，也不能据此继续追加结构。第二轮只执行其独立的分关口预算；保留路线后再修订充分调优、外部基线及正式消融的全研究总账。

- 首轮前瞻性搜索：每个可训练方法族最多8个候选配置，以seed42筛查，最多100轮；相同候选不会重复计作新试验。自有方法的架构搜索也计入这8次，不能只把学习率搜索计为预算。
- 自有方法最多4个诊断/核心结构候选，随后对保留核心架构最多4个训练配方候选，总计不超过8个；完全相同配置去重。原主干和外部方法各最多8个合理候选。不同架构即使用相同配方，也不能当作同一次训练复用。
- 主表每个最终方法用42/43/44三个种子；筛查时与最终条件完全一致的seed42结果可复用。历史开发工作和失败搜索另列，不能宣称整个研究历史的算力完全相等。
- 以4个学习方法族估算，筛查上限32次、最终额外种子8次、正式消融新增12次，总计上限52个训练任务；相同配置可减少实际数量。上一版48次扣除了4次“共享训练配方试验”，现为核心模型与原主干分别调优，不能跨架构扣减，因此修正为52。LoG/DoG扫描另记，此上限不表示必须全部运行。
- 饱和复核：最优候选在额外种子下未稳定优于参考、或最近4个有效候选的最佳开发F1改善不足0.005且没有效率/误检方面的收益时，进入停止复核。0.005是资源管理阈值，不是显著性界限；若仍在持续改善而预算已用完，应写“预算内最佳，未验证饱和”。
- 固定步数对照、学习曲线、更多交叉验证属于P6扩展预算，不静默叠加到52次。新增预算需要形成下一版计划和公平性说明，不以“还没赢”为扩展理由。
- 暂不承诺日历完成日期：先测各方法在可用硬件上的单轮耗时。当前DeepBlink的100轮约为0.6小时量级，仅用于初估；外部方法及暂停时间另算。
