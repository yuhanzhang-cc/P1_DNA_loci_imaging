# 新数据验证与标注交接草案

状态：采集/人工标注待执行，未新增数据。本文件给出采集记录和评价边界，不代表现有数据已满足生物学独立，也不代表完成样本量论证。

## 采集设计

1. 优先新做与220图相同任务、同通道/成像尺度的独立实验；记录真实生物学实验、制样、采集批次、显微镜/物镜、曝光/增益、像素尺寸及原始容器。来源文件不同不能自动视为独立生物学重复。
2. 初始资源目标可为约5个独立生物学实验、每个8–12个按位置/随机规则选取的FOV，共40–60图。这是资源规划起点，不是已计算出的显著性或power保证；应按实际实验单位和期望差异，在采集前复核样本量。若只有同一样本的很多FOV，结论仍限定为该样本。
3. 各实验保持同一选择规则，记录不可用视野及原因。不能只收集失败图、容易图或按模型得分挑视野。弱/强、稀/密、256/512原生视野可做描述性分层；不为凑分层改变像素尺度或反复裁剪同一图。
4. 先取少量非正式流程样例检查通道、导出、坐标和标注格式；不得据其表现调模型/阈值。若用于方法开发，应标记为development并从最终独立集合排除，另建排除清单。

## 标注与冻结

- 保留原始文件，仅导出目标单通道二维TIF；原生FOV≤512。大图须另行锁定分块/合并规则，不自动缩放。
- 标签CSV严格表头`y,x`，单位pixel；空图保留表头。像素尺寸不明时留空，不猜测1µm。TrackMate物理单位须按真实校准转像素并记录，不能重复转换。
- 标注人员先看原图，盲于方法身份和预测；约定弱点、邻近双点、边界、伪影的纳入规则。随机至少20%视野及全部争议点由第二人复核，保留原版、争议及共识。20%是复核工作量约定，不是误差率证明。
- 完成共识、补齐组/批次/容器身份，再生成SHA和完整manifest。冻结后一次评价；依据结果修正标签须保留原首次读出、独立说明理由及新版本，不覆盖原结果。

## 方法与结果
