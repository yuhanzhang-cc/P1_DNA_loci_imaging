# Scope 12：全分辨率heatmap＋offset强参考（H0）

状态：完成首版seed42的100轮训练，F1为0.8174，弱点检出35/96，低于新R0的41/96。尚非充分调优的正式baseline，不作为新架构贡献。不能把本地H0叫作Spotiflow复现。完整结论见[今日汇报](daily_report_20261026.md)；下文保留原设计。

## 目的与首版定义

当前碰撞很少且不在验证集，H0不是以“解决拥挤”来解释预期收益。它检验像素级密集证据、较直接的细节监督和输出表示能否改善弱点检测，为R1/R2提供真正有竞争力的参照。

沿用当前U-Net第一次编码/解码，直接在512分辨率的F0上输出1通道heatmap logit和2通道偏移，不走第二次编码。使用相同原图有效区域归一化/补齐、原像素坐标和176/22划分；参数量不同如实记录，不能称完全容量匹配。

首版冻结定义：将每个连续真值分配给`floor(y),floor(x)`像素，余数作为offset；同像素多点不得静默覆盖，先审计并明确表示限制。以这些整数锚点为中心生成`σ=1px`的Gaussian目标图，重叠处取最大值，距离锚点超过3px置0。Gaussian描述训练目标的空间容忍度，不是拟合光学PSF；亚像素位置仍由对应锚点offset表达。

使用有效像素soft Dice＋BCEWithLogits＋2×正锚点offset RMSE，各系数首版固定。offset归一化至[0,1]，与网格4的物理尺度和梯度不同，明确作为**表示/监督联合参考**。参考点周围的软标签及其余位置的零标签属于标注相对监督，不是确认所有未标注点都为背景。第一版不叠加Focal或新的弱点增强；改损失的联合效应不能写成纯拓扑贡献。

推理先在有效区域对占据图作固定3×3局部极大值提取；并列峰采用确定性位置规则，不动态扩大NMS半径；每个峰使用对应像素offset，过滤越界点，再应用全局得分阈值。主匹配半径仍为3原像素。保存低分候选，不能先以p=0.5截断再进行阈值校准。v3的keep-all指保留所有合法局部峰，与旧网格模型的候选集不同，必须保存候选数、解码定义和覆盖审计。

这一目标不是光学PSF或分割真值；Gaussian宽度和截断范围来自首版固定规则，不经测试结果调整。若要换中心图、损失、NMS或宽度，作为新的显式候选并修订预算，不能仍记H0同一次试验。

## 检查与解释

检查整数/亚像素/边缘坐标编码解码、相邻点与同像素碰撞、无点图、Gaussian交叠与截断、padding、并列峰、候选覆盖和CPU/XPU加载。几何坐标合成检查通过后才运行真实数据训练。

比较整体F1、弱点Recall、相近FP预算下Recall、参数/峰值内存/端到端耗时。若H0有效而R1无效，可以说明当前输出路线值得更换，不能直接证明“池化导致退步”，因为特征路径、表示、标签和梯度尺度同时变化。后续可用同一dense目标对比普通融合与候选交互，进行联合方法归因；需要下一版预算。

Spotiflow已采用多尺度heatmap与stereographic flow，SSHD-Net也研究点监督高分辨率网络。因此H0即使性能最好，也不通过本项目核心创新关口；它应提升基线质量，并帮助明确真正需要超过的起点。
