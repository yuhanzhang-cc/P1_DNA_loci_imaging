## 三条方案及优先级

| 方案 | 具体变化 | 提升理由与主要风险 | 研究角色 |
|---|---|---|---|
| **R1：优先核心候选** | [高分辨率细节直达＋网格内位置选择](10_detail_route.md)：在第二次池化前取特征，保留4×4内16个位置，由语义特征选择后残差更新占据/偏移 | 直接检验首轮末端头无法补回的细节；风险是放大噪声、位置选择偏向亮峰 | 结构假设；必须超过等容量的普通融合控制，创新性未确认 |
| **R2：第二核心候选** | [按位置选择上下文尺度](11_adaptive_context.md)：使用约20/36/68px范围的特征证据，保留原预测路径，不设置亮度否决规则 | 结构化背景可能需要不同范围判断；风险是平滑弱点、学到来源捷径或退化为普通大核卷积 | 独立候选，先不与R1堆叠；创新性未确认 |
| **H0：提前建立的强参考** | [全分辨率heatmap＋subpixel offset](12_dense_reference.md)，与Spotiflow官方方法分列 | 检查网格表示/池化路线是否限制当前任务，可作为后续方法的竞争起点 | 成熟路线的强基线，普通heatmap不作为核心创新 |

“更有希望”是依据失败模式和计算路径作出的研究判断，没有可验证的成功概率。R1是当前最值得先做的结构实验；H0在性能上值得优先建立，但创新空间较小；R2的机制和文献风险高于R1。不会把三者直接拼成大模型，再仅保留一个最高分。

已有工作明确覆盖了这些基础构件：Spotiflow采用多尺度heatmap与定位流；SSHD-Net已有点监督高分辨率交互；LCRNet已有动态局部上下文；PixelUnshuffle与可微位置选择也不是新算子。见[差异矩阵](related_work_delta.csv)与[来源](../references.md)。本轮只提出可检验的特定组合及对照，不宣称首次提出高分辨率、注意力或多尺度。

## 执行顺序与关口

1. **先做无训练审计。** 完成开发标注复核安排；核查train/valid重复来源和未知分组；固定弱点定义。对已有开发权重做1/2/3px平移敏感性审计时，使用原图变换、共同有效区域、映回原坐标，不将不同裁切/重标准化造成的变化混为网格效应。测量图像内相位与漏检的关系，不能从“有池化”直接推断因果。预训练强方法的开发推理可提供迁移参照，权重来源/重叠与本机兼容另登记。
2. **运行新的配对参考R0。** 训练数值配方仍为100轮、batch8、lr0.001、wd0、Dice+2RMSE。修正数据顺序控制，预先规定点F1选checkpoint与阈值的v3规则；它改变选模协议，必须从头训练R0并共同应用于新候选。具体规则及验证搜索机会见协议草案。原v2模型仍保留，不把校准/选模收益算作结构收益。
3. **先做R0、H0、R1与R1普通融合控制，共4次。** 先判断细节路线是否有净收益及特殊位置选择是否必要。H0的损失/标签表示变化单独说明，不能直接归因于网络拓扑。
4. **条件性再做R2与固定尺度控制，最多2次。** R1未解决目标背景错误，或细节直达无效且背景审计仍支持上下文问题时启用；若标签/实现审计发现主要阻碍，先处理该问题，不自动消耗两次。
5. **只复核一条入选路线。** 原主干、入选完整结构、对应简单/机制控制各追加seed43/44，最多6次。若两个结构均有信号，依预设主指标选一条复核，另一条保留为单种子探索；不额外挑种子直到获胜。

筛查准入门槛：相对同v3、同seed42的R0，点F1至少提高0.005，且弱点Recall下降不超过0.02。R1若主张保留弱点，还需在不高于R0的FP预算下看到弱点Recall至少提高0.05；R2若主张背景判别，需在各自F1工作点FP至少减少10%，同时满足弱点约束。前者为筛查门槛，后两者为机制支持目标，均非显著性判据；未达到机制目标时不能写相应机制结论，即使F1略高。相近FP预算比较仅在原注册阈值候选中进行，不为达标额外扫阈值。

通过单种子门槛也不等于有效方法。三种子同协议配对差、目标错误变化及简单控制均支持后，才进入充分调优和正式强基线比较。若只有H0或选模策略有效，则报告表示/训练或工程收益，核心架构关口仍未通过。
