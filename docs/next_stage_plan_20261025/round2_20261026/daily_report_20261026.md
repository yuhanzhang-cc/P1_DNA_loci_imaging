## 为什么暂不能宣称进步

**弱点与误检的取舍仍未解决。** R2 seed44虽然FP减少16个，却净少检14个参考点，其中弱点少检9个；三种子平均弱点Recall低于R0约2.78个百分点。该现象延续了首轮“减少FP伴随弱点损失”的问题，但不能据此断言某个注意力权重或梯度冲突是原因。

**预定机制目标均未达到。** R1在不高于R0的59个FP预算下，弱点Recall只增加3.125个百分点，未达到预定5个百分点；R2 seed42的FP为60，未实现预定10%的降低。通过宽松筛查关口不等于通过机制验证。

**S2的优势也需要控制工作点。** 在各自F1工作点，S2平均弱点Recall比R0高4.51个百分点；在各seed的R0 FP预算内，使用原31个阈值并按预定规则最大化TP，S2弱点检出为43/31/53，R0为41/41/45，总数均127。因此当前离散工作点审计没有显示平均弱点净收益。阈值网格有限，不能把它扩大解释为完整连续PR曲线的结论。

**旧220权重仍是必要的历史参照。** 旧seed42在本轮31阈值下的F1为0.8282，弱点51/96；本轮所有seed42候选均未超过它。旧三种子权重在相同阈值网格下的F1为0.8282/0.8032/0.8213，均值0.8176，高于R2的0.8103及S2的0.8143。旧权重采用历史checkpoint与训练顺序，不具有与v3相同的20个选模机会；这些数值用于防止弱对照造成错误乐观，不能单独用于结构归因，也不与旧测试F1混用。

**尚无已定位的实现故障可以解释复验结果。** 63项定向测试通过，旧权重在22张验证图上的旧/新推理路径最大绝对差为0；最终验收确认所有trial完整、参数与候选有限、同seed样本顺序一致、440个原始文件及输入NPZ哈希未变。未运行完整遗留测试集，未做独立盲法标注复核；这些边界保留。新旧R0的训练数值路径差异尚未逐项拆分，不将其全部归因为随机种子或数据质量。

## 下一步建议与停止条件

1. **停止扩展当前R2选择算子。** 不因seed42较好而继续追加核大小、注意力宽度或R1+R2叠加搜索；本轮12次预算已经完成。
2. **优先考虑补齐R1/S1的种子43/44。** 需要另登记4次训练预算，并保持当前冻结数据、代码、选模和阈值规则，复用已完成的R0配对结果。若R1不稳定超过S1，放弃“位置选择是有效核心贡献”的主张；普通细节路径仍可作为后续结构设计的参照。此项为建议，今日汇报不自动启动新预算。
3. **下一版结构应围绕弱点证据如何进入判别，而非增加抑制强度。** 在另行登记的研究中，可以比较占据/定位的独立细节路径与共享残差路径，并设置普通空间重排/投影对照；每次只改变一个可归因因素。若继续上下文方向，先用普通大核与是否排除中心位置的重新训练对照，判断S2所保留的线索是否来自上下文特征本身。
4. **先完成标注与来源审计，再作论文级验证。** 弱点是训练集局部z对比阈值定义的代理子集；当前参考点来自人工调整TrackMate参数，FP可能包含漏标。独立盲法复核仍待完成，不能自动改标注。若改标签，建立新数据版本并重训所有比较方法；独立泛化结论需要按生物学来源隔离的数据。

普通注意力、多尺度和细节重排本身不能证明新颖性。后续方法仍须通过相关工作差异、简单控制、多种子稳定性和独立验证几道关口；本轮不写“我们的最好”。
