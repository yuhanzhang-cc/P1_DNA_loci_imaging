# v3 delivery archive (2026-10-27)

This delivery contains the completed 12-run v3 screen and four R1/S1 seed
completion runs: 16 runs, 1,600 training epochs. These are development-validation
results, selected over 20 checkpoints and 31 thresholds per run, not independent
test performance. See `closing_scope_20261027.md` for the next proposed work.

Included: implementation, targeted tests, protocols, per-run source snapshots,
sample orders, training curves/logs, per-checkpoint threshold counts, selected
prediction-point tables, paired analyses, and both primary and native-loss
selected weights for every run (32 weight files).

Not included: raw images, dataset archives, local Python environments, process
locks, resume states, the 320 intermediate checkpoint weights, and the 320
candidate NPZ caches. These remain on the original workstation; the Git archive
does not support immediate resume or candidate-level reanalysis at every epoch
without regenerating those artifacts. No local artifacts were deleted.

Validation before packaging: 29 architecture/protocol tests passed. Frozen
source snapshots retain their original bytes, including pre-existing whitespace.
No new training or test-set inference was performed for this archive.
