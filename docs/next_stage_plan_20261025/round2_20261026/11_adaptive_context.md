# Scope 11：按位置选择上下文范围（R2）

状态：条件阶段及三种子复验均已完成；R2/S2平均F1为0.8103/0.8143，R2相对R0只有1/3种子为正，尺度选择的净收益未建立。第一版独立于R1，未运行组合。完整结论见[今日汇报](daily_report_20261026.md)；下文保留原设计及停止条件。

## 依据与边界

D/D2局部证据的最大采样半径为6个原图像素，主要编码中心和圆环的相对外观。它们减少部分离峰FP，却损失更多弱点。下一步可检验更大范围及不同方向的特征关系是否有用，而非再次增加环数、局部对比维度或圆形先验。

原主干卷积堆叠已经有较大理论感受野。因此R2检验的是**上下文如何被选择和利用**，不是证明原网“看不见远处”。参考标注相对FP也可能是漏标真点；未复核前不将它们自动当作生物学背景。

## 第一版计算图

1. 从原`F4`投影到16通道，保留原3通道预测头。按网格步长4构造5×5、9×9、17×17三个深度可分离上下文算子，名义覆盖约20/36/68原像素；特征原有感受野也计入实际依赖范围。
2. 每个算子直接采样位置中的中央3×3权重固定为0，只汇集邻域特征；保留方向差异，采用可学习权重，不取固定环均值。根据几何mask的有效支持比例归一化，训练/推理同规则，无有效支持时使用零向量和缺失指示。
3. 得到`C_small,C_medium,C_large`；`α=softmax(MLP([F4,C_small,C_medium,C_large,coverage]))`，每格产生三个范围的权重；`C=Σα_s C_s`。权重只依赖图像特征与有效范围，不依赖真值或样本ID。
4. `p=sigmoid(a_base+2*tanh(MLP([F4,C,coverage])))`，残差末层零初始化；offset沿用原分支。常数2为首版固定logit幅度，不按验证输赢搜索。主路径可以保留弱点证据，残差可正可负，但并不保证Recall不会下降。
5. 仍为Dice+2RMSE；无背景分割真值、PSF真值或新重建目标。73张缺少标定的图不填充虚假物理尺度，首版范围使用原图像素，按尺寸/已知标定子集描述结果，不将分层差异直接解释为物理机制。

中央采样位置排除只能约束直接聚合路径，F4各点的卷积感受野仍相互重叠，**不能称为不含点信号的纯背景分支**。同理，α不是已验证的PSF宽度、光学尺度或可解释概率。

参数增加目标≤10%、本机同条件前向中位延迟≤1.3倍。17×17核在现有XPU上的代价先做小样本实测；若不可行，记录失败或在看性能前修订配置，不把临时改小核当成同一个候选。

## 控制与淘汰

**S2固定尺度控制**保留全部三个上下文分支、残差头及主损失，使用固定`α=(1/3,1/3,1/3)`；以不参与尺度选择的普通投影匹配小量参数差，实际容量/计算差额记录。它区分“多范围特征本身”与“逐位置选择”的价值，不把删去整个分支导致的退化当作机制证据。

正式消融还应考虑普通大核上下文与不排除中央位置的替代；这两项不在本轮12次内自动训练。若没有这类控制，最多主张“相对固定融合的收益”，不能把一切改善都归因于背景分离。若最终模型同时保留R1/R2，需要另登记组合及有意义的组件对照，不能复用独立单支训练替代组合训练。

主门槛见[本轮总览](README.md)：F1净收益、弱点Recall约束，以及FP减少目标。观察α是否近似恒定、是否仅预测图像来源、不同范围支持是否在困难样例中有实际差异。若R2与S2持平，仅保留较简单方案；若FP下降主要来自弱点大量丢失，沿用首轮结论，停止该方向。

## 与最近工作的区别尚需证明

动态局部上下文并非新概念，LCRNet及高分辨率点监督SSHD-Net都需逐项对照；本仓库已有普通空洞上下文头。R2拟检验的是在原网格预测路径之外，使用排除直接中心位置、覆盖感知、逐位置选择范围的有界残差，在点坐标监督下实现弱点保留与误检控制。只有超过固定融合及普通大核替代，且差异经最近方法审查仍成立，才考虑方法贡献。有效也可能只构成工程适配。

实现边界：独立`networks/adaptive_context.py`及必要CLI注册；测试中心权重约束、缺失支持、mask归一化、全无效格、零残差等价、offset不变和模型加载。不引入全图Transformer、额外分割标签或大规模预训练。
