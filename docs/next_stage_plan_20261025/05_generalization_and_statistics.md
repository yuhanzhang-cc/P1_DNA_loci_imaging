## 主要比较与不确定性

主比较：最终自有方法与合理调优的直接DeepBlink基线，三个相同训练种子在同一22张内部测试图上的micro-F1均值差。其他强基线完整报告，不按输赢决定是否入表。

主表方法比较和结构归因分开：前者使用各自最佳合理配方，后者在共同T*下比较原主干、核心结构和必要机制控制。数据扩充、训练调优、校准与结构各自登记效应，只有最后一类及其机制证据支持架构贡献。

先检查样本ID严格配对、真值数一致、计数有限非负、无缺失图像、阈值来自验证、训练/留出不交叉。逐图指标和失败案例都保留。图像是最低重采样单元，不能把548个点、三个种子×22图或同图多个视野当作独立生物学重复。

若没有更可靠group_id，采用共同图像索引的配对bootstrap：10000次、seed20261025，对每个种子先累计重采样图像的TP/FP/FN求micro-F1，再取三种子平均差，报告百分位95%区间。此区间条件于已训练模型和当前划分；图像可交换性以及生物学独立性均有局限，种子SD另报。若已知多个图像属于同一个体/采集单元，应采用对应组级重采样；组数不足时以描述性区间为主，不制造稳定推断。

原计划以效应量和区间为主，不强制做p值。若后续确实开展多方法显著性检验，先定义主要比较与多重比较家族，采用与数据相关结构一致的配对方法，并对次要多重检验控制错误率；不对三个种子简单做t检验来宣称对整个数据域显著。

## 泛化与鲁棒性

| 检查 | 设计与边界 |
|---|---|
| 尺寸、点密度、信噪比 | 预先定义描述性分层；密度/SNR分界只由训练数据确定，报告每层图像和点数。当前256测试仅7张，不单凭其差异认定机制 |
| 图像扰动 | 对干净图和轻度噪声/背景/模糊扰动做配对，保持几何真值；强度依据训练数据与成像范围冻结，报告全部强度，不选最佳层级 |
| 匹配半径 | 固定主终点3px，另报1/2px；误差物理单位仅用于可靠标定图像 |
| 随机划分敏感性 | 如有预算，可在198张开发图内做重复划分/CV选型；反复用于选择的CV成绩叫开发证据，不叫无偏外部验证 |
| 新采集独立数据 | 最重要的最终确认。不同真实样本/采集批次，先标注并冻结再统一推理，所有方法同等评估 |

独立数据量应基于预期效应、图像/样本内相关和资源做设计模拟。可先按约50张新图像规划采集成本并覆盖多个独立样本/批次，但50不是功效保证，不能把点数当独立样本数。相关元数据未知时先补齐。新数据完全不参与本轮架构、阈值或超参数选择；若用于适配，则另留真正未使用的最终部分并区分零适配与微调实验。

若暂时没有新数据，就完成内部方法比较、消融、效率与失败案例，明确外部验证缺口，不重新随机分220张后称“独立盲测”。

## 数据效率：扩展scope，另计预算

旧89→176对照同时改变来源、尺寸组成、点数和训练步数。若想讨论“数据量”本身，从同一176张池中随机生成嵌套44/88/132/176训练子集，不按旧/新拆分；固定验证和内部测试。参考与最终方法都用同一子集清单，给出学习曲线。

分别定义两个问题：同100轮是相同样本曝光方案；同2200次更新是相同更新预算。固定步数实验需要明确max_steps、相同按步学习率规则与验证间隔（例如每110步验证，共20次），不能给小数据组更多选检查点机会。除非所有设置完全一致，不直接复用原有100轮检查点作固定步数对照。该扩展需要训练器支持和额外预算，可先用88/176两个规模做可行性验证。

## 效率与使用价值

在同一硬件、后端、精度和batch下，分别测256与512原图：预热后重复测量，GPU测时同步；记录模型前向与包含预处理/后处理的端到端耗时、峰值内存、参数量和MACs。报告中位数及波动，不用含主机待机的训练墙钟作纯GPU基准。CPU部署另成表。

使用价值先落在可支持的任务：逐图点计数误差、定位与导出、困难背景案例。没有独立细胞/细胞核掩码与真值时，不声称已证明每细胞计数、共定位或生物学功能分析更准确。计数MAE需和F1一起报告，防止FP与FN互相抵消。

产物：统一内部主表、配对差和区间、描述性分层、全部扰动曲线、效率表、独立数据状态、失败图谱。完成标准是清楚区分内部准确率、训练波动、采样不确定性、外部泛化和部署成本。
