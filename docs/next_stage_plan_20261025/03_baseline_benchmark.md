# Scope 03：公平且有代表性的baseline比较

状态：计划，修订后执行阶段P4。名单与预算在P0确定，方法适配先预检，完整调优与模型冻结在本阶段完成。核心结构设计与合理原主干训练对照分别见Scope 08/02/01。

针对“别人已经训好的模型”，先看[预训练候选与比较轨道](07_pretrained_baselines.md)：Spotiflow、U-FISH、Piscis及原版deepBlink。公开权重默认推理、验证校准与本地微调分开记录。下表的从头训练计划不代表只能从头训练，也不表示这些新增候选已完成本地训练适配。

## 基线分层

| 方法 | 角色与训练方式 | 必要说明 |
|---|---|---|
| LoG、DoG | 传统点检测参考；在开发数据选择尺度和响应阈值 | 官方实现可参考[scikit-image](https://scikit-image.org/docs/stable/auto_examples/features_detection/plot_blob.html)；两者均保留，不按测试结果挑较弱者 |
| 当前PyTorch DeepBlink | 主要直接基线；使用全部176张、合理调优、从头训练 | 自有模块应与其比较；旧113历史权重不是本轮主基线 |
| 轻量U-Net heatmap + offset | 全分辨率热图与亚像素偏移的代表性自建基线 | 明确是本项目实现；记录高斯热图宽度、峰值提取、offset标签及参数量，不能冒称某篇方法的官方复现 |
| Spotiflow | 外部专用点检测强基线候选；官方实现，自定义数据从头训练为主 | 官方[仓库](https://github.com/weigertlab/spotiflow)、[训练文档](https://weigertlab.org/spotiflow/train.html)；先核对适配、版本及硬件支持 |
| 原TensorFlow deepBlink | 可选的迁移一致性复核 | [原始实现](https://github.com/BBQuercus/deepBlink)与本项目PyTorch版属于同一方法族，不能当两个独立创新基线“凑数量” |

Spotiflow文档提供自定义训练入口；是否能在现有Intel XPU完整训练尚未验证。P0需做独立环境、极小合成数据、坐标接口、数值和训练/推理预检。若有不支持的操作，保存失败证据，评估CPU或合适的替代硬件；不能把技术失败写成低准确率。若最终未完成这个或等价强外部基线，主张范围必须缩小，不能声称优于该方法或整个领域。

预训练Spotiflow可以作为额外零样本/迁移参考，单独成表，记录模型来源与潜在训练集重叠。不能将本方法本地精调与竞争方法未经本地训练的默认预训练结果混作唯一主比较。

## 公平规则

- 所有学习方法用相同训练图、验证图和内部测试图，原图像素信息及真值一致。外部方法可用其推荐归一化、损失和优化器，必须记录，不强迫不同方法使用明显不合适的学习率或损失。
- 每个方法族最多8个前瞻性候选，seed42筛查；候选包含学习率、正则、增强、结构或后处理选择。自有方法的诊断/核心原型也计入预算；不同架构使用相同配方仍是不同训练任务，不得跨架构复用权重或重复扣减。竞争方法不能只跑一次默认值。
- 两个传统方法各最多24个尺度/抑制配置，每配置按P0最多31个阈值校准；不做逐测试图人工调参。记录确定参数所需的开发数据和人工作业量。
- 从头训练主表与外部预训练附表分开。三个训练种子42/43/44对应同一划分；不能每个方法挑最高测试种子，也不能拿本方法单次最好值对比其他方法平均值。
- 相同100轮是统一预算锚点，不保证不同模型已同样收敛。检查开发收敛曲线；发现明显未收敛时，在看新测试成绩前复核预算，提供合理的收敛配置或预算敏感性，并记录实际更新数、样本曝光、训练时间。
- 8个候选匹配的是前瞻性调参机会，不是严格相同算力。不同方法的epoch和裁块定义可能不同，需要同时记录更新步数、有效图像/patch曝光、有效像素量和设备时间；“同算力更优”需要额外预算控制实验。
- 内部模块比较尽量保持共同硬件与AMP设置。外部方法若只能换设备，可以比较精度但不能据此宣称速度第一；速度主表只用同一硬件/后端条件，另列不兼容设备结果。
- 评价都转回原始有效视野的`(y,x)`像素坐标，一套公共匹配与校准实现。方法若内部缩放/裁块，必须还原尺度与原点；NMS、平铺重叠合并等参数只用开发数据确定。

## 锁定与产物

完成每个方法的合理开发搜索后，冻结代码版本、训练数据、配置、每个种子的检查点、验证阈值、后处理和预训练状态。自有方法也同时冻结；若开发中发现还需新一轮优化，进入新的预算版本，并保留这一轮结果，不能在看内部/外部测试后偷偷替换。

产物：`baseline_preflight.md`、版本/许可证与环境清单、适配器检查、候选搜索账本、`method_locks.json`、验证结果、三种子模型及公共格式预测。未来输出放`outputs/next_stage_v2/03_baselines/`。

完成标准：至少具备合理调优的直接DeepBlink基线、传统参考、代表性替代点检测表示；外部专用强基线完成或明确记录缺口。最后比较的是每个方法在同等数据与合理预算下的最佳配置，而不是故意削弱的对手。

公开预训练Z0/Z1比较反映现成工具迁移效果。即使本地模型优于它们，也不能据此单独证明新结构有效；结构归因必须依靠同数据、同T*和同校准条件的原主干及核心机制对照。
