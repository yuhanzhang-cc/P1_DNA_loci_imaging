## 研究定位

当前选择提出有效架构方法的路线。沿用DeepBlink作可复现主干没有问题，但最终贡献需要明确且实质性的结构差异、目标机制及归因证据。更名、换数据集、重训参数、修复预处理或叠加常见模块，都不能自动成为核心方法创新。

这是本项目的选择，不是所有AI工作的唯一创新形式。学习目标、表征、数据集或训练机制也可能形成研究贡献，但若最后只剩这些收益，需重新定位研究，不能在“新架构方法”标题下完成交付。

## G1：先形成任务问题证据

目前已知：新增数据改善Recall；仍有弱点漏检、背景误检与高置信错误预测。颜色叠图和局部统计支持这些现象，但尚未确认它们的全部生物学/光学原因。不得将未知荧光结构直接命名为特定细胞器或真实未标注位点。

在198张开发图内审查误检、漏检、局部背景、点密度、点尺度和标注不确定性，形成可复核错误分类。尽量由不知道方法身份的复核者核查；不按未来内部/独立测试结果定义本方法的目标难例。

产物：`failure_taxonomy.md`、开发图像/patch索引、标注不确定清单。关口：目标失败类型有实际证据，且能够定义可测的改善指标。

## G2：与最近方法逐项对照

| 最近方法/控制 | 必须说明的区别 |
|---|---|
| DeepBlink及仓库已有上下文头 | 是否真正改变了点/背景信息交互、表征或输出推理，而不只是加一层或改名字？ |
| U-FISH、DeepSpot | 已有增强图再检点的路线；若做背景分解/增强，新的约束、监督或交互到底不同在哪里？ |
| Spotiflow | 已有空间场与位点定位设计；若做多尺度或定位场，新的机制区别是什么？ |
| Piscis | 已有面向点检测F1的学习目标；若改损失/置信度训练，如何区分目标优化与结构贡献？ |
| masked-SE、轻量空间头等简单控制 | 核心收益是否用常见、较简单的替代就能取得？ |

以上是检索起点，不是完整文献审计。官方方法来源见[references.md](references.md)及[预训练候选](07_pretrained_baselines.md)。要继续查询与拟定机制最接近的论文和官方代码，包括训练与推理细节；不能仅比较这四个名字就宣称首次。新的结构即使不全球首次，也可形成有意义改进，但主张必须与差异和证据匹配。

产物：`related_work_matrix.csv`和`novelty_delta.md`。关口：写清最近方法已经做了什么、候选具体新增什么、哪些部分只是沿用；若只能写“加注意力/增加分支”，暂不将其列为核心贡献。

## G3：核心候选设计卡

首要待研究假设D：**面向结构化荧光背景的点信号—背景交互判别**。检验现有末端特征是否难以区分点状结构与背景纹理，以及显式建模两者关系是否能减少高置信误检并保留弱点Recall。它目前只是研究假设，不能命名为已创新的网络。

拟研究的结构草图为：主干产生点证据与局部背景证据，经受约束的交互得到占据得分，定位保留明确的坐标含义。关键不是“两个头”，而是两个表征各自如何学习、为什么不会任意复制同一特征、以及交互为什么有必要。具体计算图与约束在文献和数据审查后确定。

每张设计卡必须回答：

1. 对应哪个可复核失败类型？改动发生在哪个实际计算环节？
2. 输入、特征、输出、交互和目标函数如何定义？相对最近方法新增哪一项？
3. 背景/点形态分支的训练信号从哪里来？当前只有点坐标，不能假定已有背景分割真值，也不能将所有未标注像素当作可靠负例。
4. 若采用图像重建、局部形态或平滑约束，如何防止背景分支复制整图、点分支解释所有纹理等退化解？这类约束本身也需既有工作对照。
5. 推理是否只依赖输入图像及合法元数据？缺少物理标定的73张图必须有可说明的处理，不能把默认1.0当真实微米尺度。
6. 哪个替代设计能反驳该机制？预期在哪些条件有效，又会在哪些条件失败？
7. 参数、计算、额外标签或采集信息成本是多少？如何做容量/计算控制？

T_ref固定的是主检测损失和常规优化条件。若核心机制确实需要额外辅助目标，其定义与系数属于设计卡，计入候选配置并单独记录；正式控制应尽量保留相同辅助训练信号，只改变关键结构/交互，以区分监督目标和拓扑贡献。不能加入新损失后，把全部增益直接称为架构效果。

若D与已有方法没有清晰差别或训练信号不可辨识，先修订设计卡；最多登记一个有文献与问题依据的D2替代原型。不得直接把masked-SE改名为D，也不要求为了显得创新而更换整个主干。

## G4：实现与效果关口

先用固定参考配方T_ref验证机制和结构，避免同时通过调参制造收益。实现检查通过后，只用开发/验证数据筛查。目标包括验证点F1、Precision/Recall取舍、目标误检类型、弱点表现，以及资源成本；单次最高分不足以证明有效。

正式结论须有同数据、同训练方案T*、同一冻结版本的选模/校准规则下的原主干对照；不得混用v2与未来v3分数归因。核心结构从头重训消融、简单替代、容量匹配和实际机制观测；主结果报告42/43/44而不是挑选最高测试种子。最终内部测试仍为已观察数据，独立新采集验证状态另列。

当前准确率导向架构路线的完成条件：至少一个有明确方法差异的实质性结构被保留，并有可重复、可归因的目标任务收益。只有数据扩充、阈值校准或训练调优更好，不能通过此关口。若主要价值最后变成速度/标注效率而非准确率，应明确提出研究定位修订，而不自动改写成功标准。

## G5：结论边界

将贡献分开登记：数据贡献、训练方案贡献、评估/工程贡献、结构方法贡献。+12.77个百分点只属于已有数据扩充对照；不能转移到未来新结构名下。

关口不通过时，保留失败与持平结果，标记“核心架构贡献尚未建立”，在预算内复核问题或下一版方案。不能无限试到赢、用测试集找方案，或将常见模块包装成已证明的创新。

产物：问题证据、最近方法差异表、核心设计卡、可证伪实验清单、创新证据登记和关口结论。各阶段状态至少区分：假设、实现验证、开发支持、内部对照支持、独立验证；不把计划状态写成完成状态。
